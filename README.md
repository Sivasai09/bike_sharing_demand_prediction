# 🚲 Bike Rental Demand Prediction

## 📌 Project Overview
Bike Rental Demand Prediction is a Machine Learning project that predicts the number of bike rentals based on different factors such as date, time, season, and weather conditions.

The project uses a trained Machine Learning model and a Streamlit web application to allow users to enter input values and get predicted bike rental demand.

## 🎯 Project Objective
The main objective is to predict bike rental demand based on different environmental and time-related factors.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## 📂 Project Files
- `BIKE_RENTAL.ipynb` – Jupyter Notebook containing project development and analysis.
- `app.py` – Streamlit web application.
- `bike_sharing_model.pkl` – Trained Machine Learning model.
- `bike_sharing_features.pkl` – Saved feature information.
- `requirements.txt` – Required Python libraries.

## ⚙️ How to Run the Project

### Step 1: Clone the Repository
```bash
git clone https://github.com/Sivasai09/bike_sharing_demand_prediction.git
```

### Step 2: Open the Project Folder
```bash
cd bike_sharing_demand_prediction
```

### Step 3: Install Required Libraries
```bash
pip install -r requirements.txt
```

### Step 4: Run the Streamlit Application
```bash
streamlit run app.py
```
